# resinsight-mcp

This repository contains the development foundation for resinsight-mcp.
It provides project documentation, development tools, and automated quality gates.
It does not contain an MCP server or a working ResInsight integration.

MCP is a protocol that connects agents to tools.
No application commands, simulator runs, or image responses are available from this repository.
There is no runtime demonstration or supported simulator version matrix.

Use the [development guide](development/index.md) to work on the repository.
The [local setup guide](development/local-setup.md) explains how to install the development tools and preview these pages.
The [contribution policy](https://github.com/LukasMosser/resinsight-mcp/blob/main/CONTRIBUTING.md) explains how to propose a change.
