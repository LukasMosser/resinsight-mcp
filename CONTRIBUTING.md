# Contributing

The [development guide](docs/development/index.md) explains how to contribute.
Start with the [local setup](docs/development/local-setup.md).
Follow the [agent guide](AGENTS.md) and [test and review guide](docs/development/testing-and-review.md) for each change.

Each major feature needs a pull request against `main`.
Include evidence from the commands or application behavior that the change affects.
Keep proposed work in the [implementation plan](docs/development/implementation-plan.md).
